# NEXUS Gate10 - 簡易CRM

営業部の商談進捗を月中に把握し、更新が止まった案件を見つけるためのMVPです。

## 起動手順

Node.js 22.5以上が必要です。外部パッケージは使用していません。

```bash
npm start
```

ブラウザで `http://localhost:3000` を開いてください。初回起動時にSQLiteデータベースと24件のダミー商談が作成されます。

テストは次のコマンドで実行できます。

```bash
npm test
```

## 本当に解決すべき課題

営業担当の記録が不統一・未入力のため、管理者が月中に案件の進捗と停滞を把握できないことです。

## 実装したMust機能

- ユーザー・フェーズ・商談の3テーブル
- 24件のダミー商談
- 商談一覧
- 商談登録
- 商談詳細
- フェーズと次回アクションの更新
- 最終更新から14日以上経過した進行中商談の強調

## データ構造

手書きER図に合わせて、ユーザー、フェーズ、商談の3テーブルに絞っています。

商談テーブルにはMust機能の「次回アクション更新」を保存するため、手書きER図にない `next_action` を最小限の追加属性として設けました。顧客マスタや活動履歴は作成していません。
